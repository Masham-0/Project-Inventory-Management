ALt. Inventory

Hybrid Demand Forecasting & PSO Optimization

Inventory Management using Particle Swarm Optimization

"Decide when to ReOrder stock before running out"

This project demonstrates a hybrid approach to inventory control, using machine learning to forecast demand and Particle Swarm Optimization (PSO) to compute the ideal Reorder Point (ROP) and Economic Order Quantity (EOQ). Our goal is to balance holding and ordering costs while reliably preventing stockouts so that anyone reviewing the project can understand exactly what the optimizer graphs represent.
